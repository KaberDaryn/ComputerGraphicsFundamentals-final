## Furnished studio additions

`fabric.png`, `mountains.png`, `desktop.png` and `terminal.png` are original
procedural designs maintained by `tools/generate_studio_assets.cpp` (C++17;
fabric seed 2815, embedded original bitmap alphabet). Mountain artwork is an Alatau-inspired
stylisation, not a photograph or a geographic reconstruction. The monitor editor,
terminal output and digital clock are decorative graphics.

Studio furniture, PC, headphones and other props are built from the
project's own primitives, including a new indexed torus. No downloaded 3D
models, new runtime libraries or external services were added. OpenAI Codex
assisted with scene code, original procedural textures, rendering changes,
camera regression tests and documentation. The existing official Kazakhstan
flag attribution remains applicable.

Daylight shadow mapping/PCF and alpha blending use standard OpenGL techniques;
the existing LearnOpenGL concept references below remain relevant. The glow
is a small LDR bright-pass post-process, not an HDR/PBR pipeline.

## Room refresh assets

- `assets/textures/kazakhstan_flag.png`: official flag artwork downloaded from the
  [President of Kazakhstan / Akorda](https://node1.akorda.kz/ru/state_symbols/kazakhstan_flag),
  [original JPEG](https://node1.akorda.kz/assets/media/flag.jpg), on 15 November 2026.
  Converted to RGB PNG without redrawing its symbols; displayed at a 2:1 ratio.
  Original flag design: Shaken Niyazbekov. The national symbol is credited separately
  and is not claimed as original project artwork.
- `assets/textures/rug.png`: original procedural Kazakh-inspired geometric textile,
  maintained by `tools/generate_rug.cpp` (C++17, fixed random seed 28). Includes
  diamond medallions, paired angular horn motifs and baked warp/weft grain.
  This is an original stylisation, not a copy of a historic carpet.
- Room refresh geometry, palette and textile generation code were prepared with
  OpenAI Codex assistance. No new runtime libraries or third-party 3D models.
- `assets/textures/oak_floor.png`: original procedural staggered oak boards,
  generated by the same script (fixed seed 2801); replaces the tiled floor in
  the refreshed room. No downloaded wood image is used for this new material.

Lighting, camera, texture and framebuffer concepts were informed by Joey de Vries' [LearnOpenGL](https://learnopengl.com/) tutorials. Scene geometry and shaders are project-specific. The wood and floor textures were generated for this project with OpenAI ChatGPT assistance; no third-party models are used. See the README for the AI use note.

## C++ asset tool port - 16 November 2026

The maintained generators and their RGB/PNG helper are C++17, with no external
font or imaging dependency. Existing bundled PNGs were retained; regenerating
with the C++ tools produces the same design family rather than byte-identical
copies. The PNG writer implements standard RGB8 PNG and stored zlib/DEFLATE
blocks; format references: https://www.w3.org/TR/png-3/ and RFC 1950 / RFC 1951.
No third-party PNG encoder implementation was copied into the project.
